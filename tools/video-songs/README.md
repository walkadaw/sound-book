# Песни из видео YouTube

Инструмент находит песни из спеўніка в записи с YouTube (Будслаў, пилигримки, Імша) и готовит SQL, который добавляет эти записи к песням на сайте. Вы даёте ссылку, скрипт распознаёт, что поют, и сопоставляет это с песнями. Затем вы проверяете результат на странице в браузере и забираете готовый SQL.

## Что нужно

- Windows и видеокарта NVIDIA: распознавание идёт на GPU.
- [uv](https://docs.astral.sh/uv/): `winget install astral-sh.uv`.
- ffmpeg в `PATH`: `winget install Gyan.FFmpeg`.
- Node.js: нужен yt-dlp, чтобы скачивать с YouTube.
- Любой Python 3, чтобы запустить скрипт. Своё окружение (`venv/`, Python 3.12) скрипт создаёт сам при первом запуске, это занимает несколько минут.

Модель Whisper large-v3 (около 3 ГБ) скачивается при первом распознавании и потом берётся из кэша.

## Запуск

Запускайте из корня репозитория (`C:\git\sound-book`). Команды ниже одинаково работают в Git Bash и в PowerShell. Ссылку и пути к файлам берите в кавычки, а в путях пишите прямые слэши `/`: Git Bash съедает обратные `\`.

В примерах `VIDEO_ID` и `C:/path/to/...` — заглушки: подставьте ссылку на своё видео и пути к своим файлам.

**Со своим аудиофайлом.** Это самый надёжный путь: аудио можно скачать любым сервисом.

```bash
python tools/video-songs/run.py "https://www.youtube.com/watch?v=VIDEO_ID" --audio "C:/path/to/audio.mp3"
```

Аудио должно быть звуком именно этого видео, целиком и с самого начала, иначе время песен не совпадёт с видео. Подойдёт любой формат, который читает ffmpeg: mp3, m4a, webm, wav.

**Со скачиванием с YouTube.** YouTube часто требует войти («подтвердите, что вы не бот»), поэтому нужны cookies аккаунта:

```bash
python tools/video-songs/run.py "https://youtu.be/VIDEO_ID" --cookies "C:/path/to/cookies.txt"
python tools/video-songs/run.py "https://youtu.be/VIDEO_ID" --browser firefox
```

`cookies.txt` можно выгрузить расширением браузера, например «Get cookies.txt LOCALLY», со страницы youtube.com, войдя в аккаунт. Лучше берите второстепенный аккаунт. Из Chrome и Edge `--browser` на Windows обычно не срабатывает из-за их шифрования cookies, из Firefox работает.

Подходит ссылка любого вида: `watch?v=…`, `youtu.be/…`, `shorts/…`, `live/…` или просто id видео.

Другие параметры:

| Параметр | Что делает |
|---|---|
| `--no-open` | не открывать браузер самому |
| `--port 8800` | начальный порт страницы (по умолчанию 8765; если занят, берётся следующий свободный) |
| `--model large-v3` | модель Whisper |
| `--lang be` | языки пения: `be`, `ru` или `be,ru` (по умолчанию `be,ru`). Каждый язык распознаётся отдельно, так что один язык вдвое быстрее |
| `--help` | список параметров |

## Что происходит при запуске

1. Скрипт берёт название видео с YouTube.
2. Скачивает звук или берёт ваш файл.
3. Режет его на куски по 30 минут, в моно 16 кГц, с фильтром, который поднимает тихое пение.
4. Распознаёт текст дважды: по-белорусски и по-русски, потому что в одной записи поют на обоих языках. Час записи занимает несколько минут на GPU на каждый язык.
5. Берёт свежий список песен с holysongs.ru.
6. Ищет песни в каждом распознанном тексте двумя проходами: по строкам и окнами по 2 минуты. Если оба текста нашли одну песню в одном месте, остаётся находка в первом языке из `--lang`. Куски, где ни одна песня не совпала, тоже попадают на страницу; для них показан тот текст, в котором Whisper увереннее.
7. Открывает страницу проверки на http://localhost:8765/.

Пока вы работаете со страницей, окно терминала не закрывайте. Остановить сервер — Ctrl+C.

**Повторный запуск** той же ссылки ничего не скачивает и не распознаёт заново, а сразу открывает страницу с вашими отметками. `--audio` при этом можно не указывать. Список песен каждый раз обновляется, так что песни, добавленные за это время, тоже найдутся.

## Работа на странице проверки

Слева список: найденные песни по номерам, ниже раздел «Без совпадения». Справа выбранный фрагмент: видео, время, отметка, что распознано и текст из спеўніка для сравнения.

Фильтры вверху: «Все», «Не отмечены», «Сомнительные» (низкая уверенность или второй проход) и «Без совпадения».

**Найденная песня.** Послушайте фрагмент и сравните распознанное с текстом справа. Затем отметьте:
- «Совпадает»;
- «Другая песня» — введите номер или начните вводить название, браузер подскажет песни из спеўніка;
- «Не совпадает».

**Фрагмент без совпадения.** Справа показаны три самые близкие по тексту песни. Отметьте:
- «Новая песня» — введите название, песня будет создана в спеўніке;
- «Есть в песеннике» — номер или название существующей песни;
- «Не песня» — речь, объявления. Такой фрагмент в результат не попадает.

**Время.** Границы найдены по распознаванию и могут сбиваться на несколько секунд. Поправьте их:
- кнопками ±1 и ±10;
- кнопкой «= текущее», которая ставит текущую позицию плеера;
- вводом вручную, например `2:43`.

Помогают кнопки «▶ Первые 10 с», «▶ Последние 10 с», «▶ 30 с до начала» и «▶ 30 с после конца». Если нажать на строку распознанного текста, видео проиграется с этого места.

Отметки сохраняются сразу в `work/<id>/site/verdicts.json`, так что страницу можно закрыть и вернуться позже.

## SQL для базы

Внизу списка, в блоке «Результат», нажмите **«SQL для базы»**. SQL скопируется в буфер и появится в поле под кнопкой. Если поменять отметку или время, он обновится сам.

Что в нём:
- **«Совпадает», «Другая песня», «Есть в песеннике»** дают запись в `sound_media` для нужной песни: YouTube, это видео, начало, конец, длина фрагмента, название и автор видео.
- **«Новая песня»** даёт сначала песню в `sound_list` с пустым текстом, затем запись для неё. В конце обновляется `ad_options.last_update`, чтобы сайт перезагрузил список песен. Текст новой песни потом вводится в админке.
- **«Не совпадает», «Не песня»** и неотмеченные фрагменты в SQL не попадают.

Выполните SQL в базе сайта, например через phpMyAdmin. Всё идёт одной транзакцией, а повторный запуск безопасен: песня с тем же названием и запись с той же песней, видео и началом пропускаются. Но если между запусками вы сдвинули начало фрагмента, появится вторая запись.

## Где что лежит

```
tools/video-songs/
  run.py            запуск: всё по шагам
  common.py         общее для поиска: нормализация текста, загрузка песен и распознанного
  transcribe.py     распознавание (faster-whisper на GPU)
  match.py          первый проход: строки распознанного против строк песен
  scan.py           второй проход: окна по 2 минуты
  build.py          фрагменты для страницы, включая «без совпадения»
  review.html       шаблон страницы проверки
  server.py         сервер страницы, хранит отметки
  requirements.txt  версии пакетов
  venv/             окружение Python (создаётся само, не в git)
  work/<id видео>/  всё по одному видео (не в git)
    audio.*         скачанный звук
    chunks/         нарезка для распознавания
    out/be/, out/ru/ распознанный текст по языкам
    songs.json      список песен на момент запуска
    site/           страница и verdicts.json с отметками
```

Чтобы распознать видео заново (например, другой моделью), удалите `work/<id>/out/` (или только `out/ru/`, чтобы заново распознать один язык). Если удалить `work/<id>/` целиком, пропадут и отметки.

## Если что-то не так

- **«Не удалось скачать звук»**: YouTube просит войти. Передайте `--cookies` или `--browser firefox` либо скачайте звук сами и передайте через `--audio`.
- **«Политика управления приложениями заблокировала этот файл»**: Smart App Control не пускает exe-файлы из пакетов. Поэтому скрипт всё запускает через `python`; запускайте его именно так, а не через `yt-dlp.exe` и подобные.
- **Песни не найдены или найдено мало**: Whisper плохо слышит пение толпы под открытым небом. Посмотрите раздел «Без совпадения» и «Сомнительные»: там часто есть песни, которые можно сопоставить вручную.
- **Плеер не играет (ошибка 153)**: открывайте страницу через адрес `http://localhost:…`, а не как файл с диска.
- **В плеере «Видео недоступно»**: YouTube не встраивает видео в страницу, открытую по адресу `http://127.0.0.1:…`. Откройте её через `http://localhost:…` (тот же порт).
