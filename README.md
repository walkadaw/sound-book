# SoundBook (Спеўнік)

Спеўнік — сборник духоўных песень з акордамі для касцёльнай супольнасці.

## Для чаго

Дапамагае знайсці патрэбную песню падчас набажэнства ці рэпетыцыі і карыстацца ёй без папяровага зборніка: хутка шукаць, чытаць з экрана, і адразу пераносіць акорды пад зручную танальнасць.

## Магчымасці

- **Пошук песень** — хуткі пошук па назве і тэксце з падсветкай супадзенняў.
- **Акорды** — акорды над тэкстам песні з магчымасцю транспанавання ў любую танальнасць.
- **Літургія і гадзінкі** — асобныя раздзелы для тэкстаў Імшы і Літургіі гадзін.
- **Плэйлісты і абраныя** — складанне спісаў песень для канкрэтнага набажэнства і захаванне ўпадабаных.
- **Рэжым прэзентацыі** — паказ тэксту песні на поўным экране, зручны для праекцыі.
- **Генератар для друку** — падрыхтоўка і друк падборкі песень.
